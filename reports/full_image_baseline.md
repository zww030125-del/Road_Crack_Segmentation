# 整图 ResNet18 U-Net 基准

这套基准用于后续结构实验。网络沿用原版 ResNet18 U-Net，编码器从 ImageNet 权重初始化并全程冻结，包括 BatchNorm 运行统计量。解码器随机初始化，训练只更新解码器和输出层。

## 数据与训练

- DeepCrack537 原训练集按固定种子 42 划分为 240 张训练图和 60 张验证图。训练和验证均使用原尺寸整图，本地这 300 张图均为 `544×384`。RGB 缩放至 `[0, 1]`，Mask 以灰度值 `> 127` 二值化。ImageNet 归一化由网络内部完成。
- 默认训练种子 42，训练 15 轮。使用 Adam、学习率 `1e-3`、FP32、batch size 1，每两张图累积一次梯度。末组按实际图像数归一化。
- 损失为 `Weighted BCE + 0.5 × Dice Loss + 0.25 × soft-clDice`。BCE 的正类权重为 5，软骨架迭代 10 次。无裂纹图仍参与 BCE 和 Dice 监督。
- 仅对训练 RGB 以 0.7 的概率联合增强亮度和对比度。以各通道空间均值 `m` 为中心，应用 `clip((I - m) × α + m + β, 0, 1)`，其中 `α` 均匀采样自 `[0.65, 1.10]`，`β` 均匀采样自 `[-0.05, 0.05]`。

## 整图困难采样

在未增强的训练图上，从标注提取真实骨架。以二值 Mask 欧氏距离变换的两倍估计宽度，以灰度图的 `21×21` 局部均值减原灰度并截断到非负估计暗线对比度。将宽度 `≤3 px` 且对比度 `≤0.0779` 的骨架点占该图全部真实骨架点的比例作为困难分数。对比度阈值沿用第 41、45 课历史验证诊断的定义。 [宽度与对比度分析](../lesson45_width_contrast.py)

每轮纳入全部 240 张训练图，再按困难分数排序，额外训练排名前 25% 且包含困难点的图像各一次。分数相同则按困难点数降序、文件名升序排列。当前选出 60 张，每轮共输入 300 次整图。训练时同一图的两次出现可获得不同的随机增强。

## 整图验证与选权

每轮在相同的 60 张完整验证图上扫阈值 `0.05–0.95`，步长 `0.01`。按像素汇总 TP、FP 和 FN 计算 Micro Dice，选择最高验证 Micro Dice 对应的权重和阈值。Dice 相同时优先较早轮次和较低阈值。另报告该权重在 Micro Precision `≥0.85` 条件下达到最高 Micro Recall 时的细且低对比骨架覆盖率，覆盖以骨架点的 `5×5` 邻域内是否有预测前景为准。237 张测试图留作后续独立评估。

本轮指标描述的是整个训练配方。相较于第 50 课冻结编码器的整图对照，本轮每轮增加 25% 的训练图像输入次数，并同时使用 soft-clDice 和亮度、对比度增强。后续结构对照可固定划分、训练配方与选权协议。

## 基准结果

训练种子 42，共 15 轮，第 12 轮权重入选。下表两行使用同一份权重和同一批 60 张完整验证图，只切换二值化阈值。

| 阈值选择 | 阈值 | Micro Precision | Micro Recall | Micro Dice | Micro IoU | 细且低对比骨架 Recall |
|---|---:|---:|---:|---:|---:|---:|
| 最高 Micro Dice | 0.84 | 0.86152 | 0.87066 | 0.86607 | 0.76377 | 75.21%（1711/2275） |
| Micro Precision ≥ 0.85 下最高 Micro Recall | 0.76 | 0.85035 | 0.88169 | 0.86574 | 0.76326 | 75.52%（1718/2275） |

旧的冻结编码器整图对照在同样的 60 张完整验证图和阈值网格上，最高 Micro Dice 为 0.85905。本轮高约 0.70 个百分点。训练预算和多项策略同时变化，且本轮只运行了一个训练种子，差值只能作为整套配方的观察结果。 [旧整图对照](full_validation_comparison.csv)

## 复现

在项目根目录运行。首次使用 ImageNet 预训练编码器需下载相应权重，或使用已有的 PyTorch 权重缓存。

```bash
python -m pip install -r requirements-dev.txt
python -m pip install scipy scikit-image
python train_full_image_baseline.py
```

训练入口支持 `--seed`、`--epochs` 和 `--output`。默认目录为 `outputs/full_image_baseline/seed_42/`，重跑可指定新目录。使用 `ResNetUNet(pretrained=False, freeze_encoder=True)` 加载 `best_model.pth` 后，按 `summary.json` 记录的阈值对整图输出做二值化。该目录也保存逐轮日志、选中权重的阈值扫描和训练图难度排名。
